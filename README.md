# roundtable

回合制战役与存档产品的本地命令行入口。支持单场遭遇与两场连续战役，均可跨进程续玩。
需要 Node.js 24，使用 ES modules，无外部运行依赖。

## 用法

```sh
node app.js                                  # 显示帮助
node app.js --help | -h                      # 显示帮助
node app.js new <存档路径> <角色名>           # 新建单场遭遇（存档已存在则报错，不覆盖）
node app.js campaign <存档路径> <角色名>      # 新建两场连续战役（存档已存在则报错，不覆盖）
node app.js status <存档路径>                # 查看当前状态
node app.js act <存档路径> <行动>            # 提交行动：attack | defend | potion
node app.js next <存档路径>                  # 战役首场胜利后进入第二场
node app.js log <存档路径>                   # 按场次与回合查看行动记录
```

存档为本地 JSON 文件，路径自定；不同存档互不影响。每次调用自动读取所选存档，
`status`、`log` 不会改写存档。`new` 与 `campaign` 不会覆盖已有文件。

`act` 的行动也可用简写 `a`/`d`/`p` 或中文 `攻击`/`防御`/`喝药`。
角色名可含空格，按命令行上的多个参数拼接（如 `node app.js campaign save.json 亚瑟 王`）。

## 单场遭遇规则（new）

- 角色：生命上限 10、攻击 4、治疗药 1 瓶（恢复 6，不超过上限；满血或无药时拒绝）。
- 敌人：生命 12、攻击 3。回合从 1 开始，规则固定，不使用随机数。
- 行动：`attack` 扣敌人 4 点生命；`defend` 使本回合敌方伤害降为 1（不叠加）；
  `potion` 消耗一瓶并恢复 6 点生命。
- 每个有效行动构成完整回合：先结算玩家效果，敌人死亡立即胜利且不反击；
  否则敌人反击，角色死亡立即失败；双方存活则进入下一回合。生命最低为 0。
- 无效行动不触发反击、不推进回合、不消耗物品、不追加记录。
- 终局后拒绝继续行动，但仍可查看状态和记录。

## 两场连续战役规则（campaign / next）

- 角色：生命上限及初始生命 10、攻击 4、治疗药 1 瓶；攻防、防御减伤、喝药与
  拒绝喝药规则与单场相同。
- 第一场敌人生命 12、攻击 3；第二场敌人生命 16、攻击 3；每场回合都从 1 开始。
- 每场都先结算玩家效果：杀敌的回合敌人不反击，否则敌人反击；生命最低为 0；
  无效行动不改变任何进度。
- 第一场胜利的**致命回合同时**恢复角色 4 点生命（不超过 10）并增加 1 瓶治疗药，
  随后进入「等待下一场」状态。胜利不结束整个战役，等待期间拒绝一切战斗行动。
- 只有等待状态可以执行 `next`：保留角色当前生命与药瓶，重新初始化敌人
  （生命 16、攻击 3）与回合（从 1 开始），且**不重复发放**首场奖励。
  进入第二场后重复执行 `next` 会被拒绝且不改动存档。
- 第二场胜利即完成整个战役；任何一场角色死亡都判为战役失败，此后禁止
  `next` 与继续行动。
- `status` 区分当前场次、当前或结束回合、角色生命与药瓶、敌人生命、等待状态及
  战役结局；`log` 按发生顺序保留两场完整回合记录，标明场次、实际伤害与治疗、
  结算后生命，并显示首场胜利奖励与场间切换。重启进程后信息与可执行操作一致。

## 存档可靠性

- 每次有效行动或场间切换，战斗结果、奖励、场次进度与全部记录作为一个整体
  原子写入（临时文件 + fsync + rename），成功退出 0；进程中断只会读到
  操作前或操作后的完整状态，不会重复领奖或丢失前场记录。
- 新建（含战役）通过硬链接落位，已有存档不会被覆盖；失败的新建不留下
  可误认的存档文件。
- 保存失败时保留原存档字节，业务或保存失败退出 1 并说明原因。
- 读取战役存档时按规则完整重放两场的行动、奖励与场间切换；越界、重复奖励、
  非法切换或状态与记录矛盾时拒绝继续，不清空也不覆盖损坏存档。
- 旧的单场存档仍按单场规则游玩，不会自动变成战役。

退出码：0 成功；1 业务/运行错误（含存档问题、无效行动、保存失败）；
2 参数错误或未知命令（含 `constructor`、`__proto__` 等）。
